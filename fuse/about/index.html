About Fuse 0xAC

Fuse 0xAC is a short puzzle game about guarding one number. Memory address 0xAC holds the value 172. Everyone wants it changed. You're the operator who decides what gets through.

It plays like a border checkpoint for data. Packets arrive one at a time. Each one asks to read memory, write memory, file a report or borrow the bus. You check it against the rulebook and press Accept or Reject. If you reject a packet, you also pick the rule it broke.

How to play

  • Accept packets that follow every rule. Rejecting an honest packet earns a citation and costs a few points.
  • Reject packets that break a rule, and choose the reason. A correct reason earns full points. The right call with the wrong reason earns a little.
  • Let a hostile packet through and the fuse loses integrity. After three, it breaks and reads 173.
  • Correct calls in a row build a combo multiplier, up to ×4.
  • From day 2 you get one honeypot per shift. Use it on a packet you're sure is hostile for bonus points. Use it on an honest packet and it costs you.
  • Keyboard: A accept, R reject, number keys to pick a reason, H honeypot, Esc to cancel.

The week

The campaign runs five days. Each day adds new rules, and the rulebook marks them so you can catch up.

  • Day 1, Orientation. The memory map: open userland, signed kernel space, and the fuse itself. Hex and decimal.
  • Day 2, Notation. Octal and binary arrive, along with strings and decimals pretending to be numbers. The decoder tab helps.
  • Day 3, Evidence. Reports, screenshots and quotes. Check each author's key in the dossier and compare the hashes.
  • Day 4, Signatures. Issuers, expiry dates, revoked serials and look-alike names. The terminal is also acting up.
  • Day 5, The Bus. Direct memory access requests that cover whole ranges at once, and one very official-looking override.

Finish the week to unlock endless mode. Every rule is active, each shift brings a fresh grant code, and it keeps going until the fuse breaks.

What it teaches, quietly

Under the jokes, the game practises real ideas: the same number written in hexadecimal, octal, binary and decimal; the difference between a number and text that looks like one; checking where evidence came from rather than what it claims; and how certificates, expiry and revocation decide whether a signature means anything.
